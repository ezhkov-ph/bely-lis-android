**Белый лис** — открытый Android-браузер на базе Mozilla Firefox, GeckoView и NSS со встроенными сертификатами `Russian Trusted Root CA` и `Russian Trusted Sub CA`. Он предназначен для совместимости с российскими сайтами, которым нужна эта цепочка доверия, включая отдельные государственные сервисы, Госуслуги, банки и другие организации. Доступность конкретного сайта не гарантируется.

*White Fox is an independent Firefox for Android fork with an additional Russian trusted CA chain. It is intended as a secondary browser for websites that require Russian TLS certificates.*

> [!WARNING]
> **Не рекомендуется использовать «Белый лис» как основной браузер.** Дополнительный корневой сертификат расширяет круг удостоверяющих центров, которым доверяет браузер. У российской цепочки доверия есть существенные вопросы с точки зрения безопасности, прозрачности и области применения. Устанавливайте приложение только для сайтов, которые без неё не открываются, желательно в отдельный профиль Android, «Второе пространство» или на отдельное устройство.

## Назначение

Некоторые российские государственные и коммерческие сайты используют TLS-сертификаты, построенные на российском удостоверяющем центре. Обычный Firefox может не считать такую цепочку доверенной. «Белый лис» добавляет российский корневой и промежуточный сертификаты непосредственно в хранилище NSS браузера.

Проект основан на исходном коде **Mozilla Firefox for Android**. Движок и стандартная проверка HTTPS сохраняются. Изменения проекта ограничены собственной идентичностью приложения, графикой, текстовым брендингом, отдельным package ID и добавленной цепочкой сертификатов.

**Это не официальный продукт Mozilla.** Проект не связан с Mozilla, не поддерживается и не одобрен ею. Firefox и Mozilla являются товарными знаками Mozilla Foundation.

## Как использовать безопаснее

Используйте «Белый лис» как специализированный второй браузер:

- открывайте в нём только сайты, которым нужна российская цепочка;
- не храните в нём основные пароли, историю и постоянные сессии;
- не назначайте его браузером по умолчанию;
- по возможности установите его в отдельный профиль Android или «Второе пространство»;
- для обычного интернета продолжайте использовать официальный Firefox или другой основной браузер;
- скачивайте APK только из Releases этого репозитория и сверяйте SHA-256.

Добавленный корневой сертификат **не ограничен российскими доменами**. Браузер может доверять любой формально допустимой серверной цепочке до этого CA независимо от доменной зоны. Проект не изменяет системное хранилище Android, не отключает проверку HTTPS, не добавляет ГОСТ-криптографию и не предоставляет электронную подпись.

## Установка рядом с Firefox

Релизная сборка использует собственный идентификатор:

```text
ru.belylis.browser
```

APK подписывается отдельным ключом проекта. Поэтому «Белый лис» устанавливается рядом с официальным Firefox и не заменяет его. Все обновления должны быть подписаны тем же ключом; при его утрате Android не позволит обновить уже установленное приложение.

## Изменения

- в NSS добавлены `Russian Trusted Root CA` и `Russian Trusted Sub CA`;
- приложение переименовано в «Белый лис» без удаления юридически значимых упоминаний Mozilla;
- добавлены собственные значок и приветственная иллюстрация;
- задан отдельный package ID и отдельная релизная подпись;
- добавлены проверки сертификатов, брендинга, подписи и параметров APK.

Текущая основа: **Firefox Android 154.0.1**, тег `FIREFOX-ANDROID_154_0_1_RELEASE`, ревизия `9cd094dbc3eac5df87a24e7a871e52880cb8cd42`.

## Установка APK

Релизы рассчитаны на устройства **ARM64**.

1. Скачайте APK и `SHA256SUMS.release` со страницы Releases.
2. Сверьте SHA-256 APK.
3. Разрешите установку из выбранного источника только на время установки.
4. Установите APK и снова отключите это разрешение.

Публикация новой версии не устанавливает её на телефон автоматически. Android может запрашивать подтверждение каждого обновления.

## Сертификаты

Отпечатки закреплены в [`config/certificates.json`](config/certificates.json). Подготовка сборки проверяет SHA-256, срок действия, CA-флаг, ключ и подпись промежуточного сертификата. Корневой сертификат получает доверие только для TLS-аутентификации серверов; промежуточный добавляется без самостоятельного корневого доверия.

Срок текущего промежуточного сертификата заканчивается **6 марта 2027 года**. Замена сертификата всегда требует ручной проверки происхождения и отпечатка.

## Сборка

Репозиторий хранит проверяемые преобразования, а не полное исходное дерево Firefox. Каталоги `work/`, `artifacts/`, Android SDK, ключ подписи и локальные секреты в Git не включаются.

```powershell
node scripts/fetch-inputs.mjs
npm test
node scripts/prepare-overlay.mjs
& 'C:\Windows\System32\wsl.exe' -d Ubuntu --exec python3 '/mnt/c/Users/alex/Downloads/Firefox ru/scripts/validate-branding.py'
```

Для добавления сертификатов нужна полная сборка GeckoView/NSS. Локальный ARM64 release собирается в WSL2:

```powershell
& 'C:\Windows\System32\wsl.exe' -d Ubuntu --user root --exec bash `
  '/mnt/c/Users/alex/Downloads/Firefox ru/scripts/build-session.sh' release
```

Ход сборки:

```powershell
powershell -ExecutionPolicy Bypass -File '.\scripts\watch-release.ps1'
```

Технические детали находятся в [описании брендинга](docs/TEXT-BRANDING.md) и [матрице проверок](docs/TEST-MATRIX.md).

## Автоматические обновления

[`scripts/auto-release.ps1`](scripts/auto-release.ps1) проверяет официальный стабильный выпуск Firefox Android, переносит проверяемые изменения, собирает и подписывает APK. GitHub Release создаётся только после успешной проверки. Если структура Firefox изменилась несовместимо, публикация отменяется, а предыдущий релиз остаётся доступным.

Настройки автоматизации находятся в [`config/automation.json`](config/automation.json). Для работы нужны настроенный GitHub remote, `gh auth login`, резервная копия ключа подписи и успешный ручной выпуск.

```powershell
powershell -ExecutionPolicy Bypass -File '.\scripts\install-auto-release-task.ps1'
```

Проверка запускается через пять минут после входа в Windows и дополнительно раз в сутки.

## Частые вопросы

### Это официальный Firefox с российскими сертификатами?

Нет. Это независимый форк Firefox Android. Mozilla не выпускает, не проверяет и не поддерживает «Белый лис».

### Можно ли установить его рядом с обычным Firefox?

Да. Package ID `ru.belylis.browser` и отдельная подпись позволяют одновременно держать на Android официальный Firefox и «Белый лис».

### Открывает ли браузер Госуслуги и сайты российских банков?

Добавленная цепочка устраняет ошибку недоверенного TLS-сертификата на сайтах, использующих соответствующий российский CA. Сайт может иметь дополнительные ограничения, поэтому совместимость с каждым сервисом проверяется отдельно.

### Почему не стоит использовать его как основной браузер?

Встроенный корневой CA расширяет доверие браузера и не ограничивается списком российских доменов. Для повседневного просмотра безопаснее использовать официальный браузер, а «Белый лис» запускать только для необходимых сайтов.

### Где скачать APK?

После публикации проверенные ARM64 APK размещаются только в разделе **Releases** этого репозитория вместе с SHA-256 и отчётом сборки. APK из сторонних источников проект не контролирует.

### Как обновляется браузер?

Локальная автоматизация проверяет официальный stable-релиз Firefox Android. Если патчи, сертификаты, подпись и итоговый APK проходят проверки, создаётся новый GitHub Release. Несовместимое изменение исходников останавливает выпуск.

## Ограничения

«Белый лис» собирается из стабильного Firefox, но является сторонней модификацией. Проверки и аудит Firefox не распространяются автоматически на изменённый APK. Проект не гарантирует доступность конкретного сайта, безопасность банковской операции или своевременность обновления.
